# Wild Wonder Atlas website

Static site for Wild Wonder Atlas (animated wildlife stories) and the Wild Wonder Atlas Publisher desktop app.

- `index.html` – home, episodes, where to watch, about, contact
- `publisher.html` – Wild Wonder Atlas Publisher (TikTok Login Kit + Content Posting API, upload mode)
- `privacy.html`, `terms.html` – Privacy Policy and Terms of Service

Published with GitHub Pages.
